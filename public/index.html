IndexError: list index out of range

AI Confidence
95%
Problematic Line
Line 2

What Went Wrong?

The code is attempting to access an element at index 5 from a list that only contains 3 elements.

Why Did It Happen?

In Python, list indexing is zero-based: for a list with 3 items, valid indices are 0, 1, and 2. Index 5 is outside the bounds of the allocated sequence.

Original Problematic Code

Original (Failing) 
numbers = [10, 20, 30]
print(numbers[5])  # <-- IndexError here

Suggested Fix

Corrected Solution 
numbers = [10, 20, 30]

if len(numbers) > 5:
    print(numbers[5])
else:
    print("Index does not exist")

Why This Fix Works

  • Lists use 0-based indexing. The valid indices are 0, 1, and 2.
  • Checking len(numbers) > 5 guards against bounds violations before element access.
  • An alternate defensive approach is using a try / except IndexError block.

Prevention Tips

  • Always check container length or use bounds verification before indexing.
  • Prefer iterating directly with for item in numbers: rather than manual indexing.
  • Use safe getter utilities or exception guards when processing external inputs.
